# DigitalOB Hub

**Organizational Behavior for the Digital Workplace**

An interactive knowledge platform, diagnostic suite, and operational toolkit designed to translate behavioral science into high-trust operating systems for distributed, hybrid, and AI-augmented teams.

---

## 🧭 Executive Summary

Traditional Organizational Behavior (OB) was conceived in an era of co-located office spaces, synchronous physical observation, and hierarchical managerial pyramids. When companies move to digital, remote, or hybrid environments without restructuring their behavioral assumptions, they default to **digital presenteeism**: equating productivity with active green chat dots, packing calendars with defensive video calls, and deploying intrusive electronic surveillance.

DigitalOB Hub bridges the gap between academic organizational psychology and day-to-day digital execution. It provides a university-grade repository of organizational behavior concepts alongside interactive, real-world tools that engineering leads, product managers, and people-operations teams can use to build high-trust, asynchronous, and outcome-oriented organizations.

---

## ❓ The Core Problem: Why Does This Project Exist?

The transition to digital work is not a software tooling challenge; it is a **behavioral coordination crisis**:

- **The Surveillance Trap vs. True Autonomy** — When managers lose visual line-of-sight, many resort to Electronic Performance Monitoring (EPM)—logging keystrokes, monitoring screen captures, or scrutinizing login hours. Self-Determination Theory (Deci & Ryan) demonstrates that intrusive control dismantles intrinsic motivation, fuels turnover, and breeds cynical compliance.
- **The "Always-On" Collapse of Work-Home Boundaries** — Without physical commutes to mark the boundary between office and personal life, employees experience persistent *telepressure*—the urge to answer messages immediately regardless of the hour. This suppresses psychological detachment, producing chronic cognitive burnout.
- **The Negativity Bias of Lean Digital Media** — Text messages, code reviews, and issue tickets lack vocal inflection and body language. Human brains systematically fill this contextual vacuum with negative assumptions, turning healthy technical debates (task conflict) into toxic interpersonal friction (relationship conflict).
- **The Hybrid Inequity Dilemma** — In hybrid configurations, leaders unconsciously favor physically visible employees for choice projects, recognition, and promotions (*proximity bias*), regardless of whether remote colleagues produce superior verifiable outcomes.

DigitalOB Hub exists to replace these ad-hoc, defensive habits with explicit, research-backed management systems.

## 🔮 The Future of Work: Why Digital OB Matters

The modern workplace is evolving beyond emergency remote work into structured, intelligent digital headquarters characterized by several shifts:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      THE EVOLUTION OF WORK ARCHITECTURE                 │
├──────────────────────────┬──────────────────────────────────────────────┤
│ Industrial / Office Era  │ Visual supervision, 9-to-5 synchronous time, │
│                          │ informal physical hallway osmosis.           │
├──────────────────────────┼──────────────────────────────────────────────┤
│ Remote / Pandemic Era    │ Lift-and-shift of physical habits to Zoom,   │
│                          │ calendar sprawl, digital presenteeism.       │
├──────────────────────────┼──────────────────────────────────────────────┤
│ Modern Digital Future    │ Asynchronous-first specs, outcome telemetry, │
│                          │ Human-AI co-intelligence, and boundary laws. │
└──────────────────────────┴──────────────────────────────────────────────┘
```

### 1. Human-AI Teaming as the Default Unit
Generative AI models and autonomous agents are no longer novelty tools; they act as digital co-workers. This introduces new organizational questions: How do teams calibrate trust when navigating AI's *jagged capability frontier* (Dell'Acqua et al., 2023)? How do junior engineers build competence when entry-level synthesis is automated? Digital OB provides the socio-technical frameworks to manage human-AI division of labor.

### 2. Documentation as Core Infrastructure
In globally dispersed teams, documentation is the organization's architecture. Following Conway's Law (1968), a decoupled, modular codebase requires decoupled, asynchronous communication. Digital OB treats public RFCs, written decision logs, and transparent roadmaps as foundational drivers of organizational velocity.

### 3. Sustainable Cognitive Capacity as a Business Moat
In knowledge work, *attention residue* (Leroy, 2009) and constant context switching represent severe productivity drains. The competitive advantage belongs to organizations that protect deep focus, enforce explicit right-to-disconnect boundaries, and treat *psychological detachment* (Sonnentag & Fritz, 2007) as a prerequisite for high-value problem-solving.

## ⏰ When to Use DigitalOB Hub

This platform is engineered for key operational inflection points:

- **When Spinning Up New Teams or Sprints** — Use the Team Charter Generator during "Sprint Zero" or team onboarding to eliminate ambiguity around response-time SLAs, core sync windows, and escalation routes.
- **When Diagnosing Cultural Friction & Exhaustion** — Run the Digital OB Health Audit quarterly to benchmark psychological safety, meeting overload, and telepressure before burnout causes attrition.
- **When Transitioning to Hybrid or Remote Models** — Reference the Structural Comparison Matrix and Leadership Playbook to prevent proximity bias and implement the "One-in-Virtual, All-in-Virtual" standard.
- **When Resolving Asynchronous Communication Breakdowns** — Consult the Lexicon and 12-Module Academic Curriculum to train managers on the Fundamental Attribution Error in text-based communications and the difference between task vs. relationship conflict.
- **When Establishing Fair Evaluation Criteria** — Replace activity metrics (keystrokes, PR velocity) with evidence-based calibration frameworks grounded in documented business impact.

### Module 1: The Three Levels of Digital OB
- **Micro OB (Individual):** Attention residue, cognitive offloading, Self-Determination Theory (autonomy, competence, relatedness), and work-home boundary management.
- **Meso OB (Team & Groups):** Swift trust formation, text-first psychological safety, human-AI pairing styles (Centaurs vs. Cyborgs), and hybrid equity.
- **Macro OB (Organization):** Conway's Law, open-by-default knowledge architectures, algorithmic governance, and cross-cultural communication context.

### Module 2: Interactive Team Working Agreement (Charter) Builder
A client-side generator that converts team agreements into clean, standardized Markdown:
- Configure response turnaround times (e.g., 4-hour SLA during working hours).
- Calculate shared synchronous windows (e.g., 2-hour daily overlap across a 6-hour timezone spread).
- Define the single source of truth for architectural decision records (ADRs).
- Establish explicit rules for off-hours disconnection and high-severity escalation channels.
- Export matched `.md` files directly to Git repositories or internal wikis.

### Module 3: Digital OB Team Health Audit
A 6-dimension diagnostic self-assessment scoring teams out of 30 points across:
1. Asynchronous Documentation Maturity
2. Output-Based Trust vs. Presenteeism
3. Psychological Safety in Digital Channels
4. Off-Hours Boundary Protection
5. Critical Human-AI Collaboration Balance
6. Hybrid Proximity Equity

Outputs an interactive Recharts radar chart, an animated SVG score gauge, and categorized action plans tailored to one of three health tiers:
- **Crisis** (6–14)
- **Fragmented** (15–22)
- **High-Trust / Elite Async** (23–30)

### Module 4: The Searchable Lexicon (36 Terms)
A fast, client-side index covering critical socio-technical vocabulary—from *Swift Trust* (Meyerson et al., 1996) and *Proximity Bias* (Bloom et al., 2015) to *Jagged Frontier* (Dell'Acqua et al., 2023) and *Technostress* (Tarafdar et al., 2007). Features category filtering and deep-linkable URLs (`/lexicon#term-id`).

### Module 5: The 12-Module Academic Syllabus
An end-to-end curriculum bridging foundational behavioral science (Tuckman, Schein, Bandura, French & Raven, Hofstede) with modern digital workplace scenarios and concrete countermeasures.

## 💻 Tech Stack & Architecture

Built with a modern, high-performance client-side stack:

- **Framework:** React 19 + Vite 6
- **Routing:** React Router v7 (declarative routing via `react-router`)
- **Styling:** Tailwind CSS v4 (CSS-first `@theme` configuration via `@tailwindcss/vite`)
- **Animation:** Framer Motion (`layoutId` sliding indicators, spring physics, accessible `useReducedMotion()`)
- **Data Visualization:** Recharts (interactive radar profiles) + Custom Animated SVG Gauges
- **Icons:** Lucide React (tree-shaken icon library)
- **Deployment:** Zero-backend, static client-side bundle deployable to Vercel, Netlify, or GitHub Pages.

## 🚀 Quickstart Guide

### Prerequisites
- **Node.js:** Version 22.2.0 or higher (`node -v`)
- **npm:** Version 10 or higher

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/your-username/digitalob-hub.git
cd digitalob-hub

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to explore the hub.

### Production Build

```bash
# Compile and optimize static assets
npm run build

# Preview the production build locally
npm run preview
```

### Deploying to GitHub Pages

To deploy to a GitHub Pages repository sub-path:

1. In `vite.config.js`, add:

```js
export default defineConfig({
  base: '/digitalob-hub/',
  plugins: [react(), tailwindcss()],
})
```

2. In `src/main.jsx`, supply the `basename` to the router:

```jsx
<BrowserRouter basename="/digitalob-hub">
```

3. Run `npm run build` and push the `dist/` folder to your `gh-pages` branch.
